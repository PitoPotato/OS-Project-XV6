Q2. What is p->trapframe->a7 and what does it represent?
Answer: The value of p->trapframe->a7 is 0xf (15 in decimal), which represents the SYS_open system call. It indicates that the process is requesting the kernel to open a file.

Q3. What was the previous CPU mode?
Answer: User mode

    Evidence:
    (gdb) p /x $sstatus
    $2 = 0x200000022
    Bit 8, known as SPP (Supervisor Previous Privilege), records the CPU's privilege mode before the trap occurred. Since SPP = 0, the CPU was previously in User mode before switching to Supervisor mode to handle the system call.

Q4. Which assembly instruction panics? Which register is num?

    Evidence:
    hart 1 starting

Q5. Why does the kernel crash?
Answer: The kernel crashes because it attempts to read memory at address 0x0, which is not mapped in the kernel's address space

    Evidence:
    scause = 0xd indicates a load page fault, and stval = 0x0 identifies the invalid memory address.
